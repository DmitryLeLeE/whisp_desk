# Журнал изменений

## 1.1.0

- **Фоновая музыка с умным авто-приглушением (BGM with Auto-Ducking)**:
  - Добавление подложки фоновой музыки с бесконечным циклом (`-stream_loop -1`).
  - Умный дакинг через FFmpeg `sidechaincompress`: громкость музыки плавно затухает на 7x при появлении голоса спикера и возвращается в естественных паузах между словами.
  - Настройка громкости (от 2% до 50%, по умолчанию 15%) и тумблер включения/выключения Sidechain в настройках рендера.
- **Интерактивная караоке-подсветка активного слова (Word-by-Word Karaoke Subtitles)**:
  - Пословная подсветка речи в стиле Shorts/Reels/TikTok на основе временных меток Whisp.
  - Динамическая смена цвета текущего произносимого слова с помощью ASS override тегов (`{\c&H00EAFF&}`).
  - Выбор акцентного цвета подсветки (по умолчанию #FFEA00) прямо в интерфейсе экспорта.
- **Пресеты платформ экспорта в 1 клик (1-Click Platform Presets)**:
  - ✈️ **Telegram Fast**: 720p, быстрое кодирование, компактный вес для отправки в мессенджер.
  - 🎬 **YouTube Master**: 1080p, -14 LUFS, повышенная чёткость речи (Clarity Enhancer), наивысшее качество.
  - 📱 **Shorts / Reels 9:16**: вертикальный кадр 1080x1920, Hardsub с караоке-подсветкой активного слова.
  - 🎙️ **Подкаст MP3**: экспорт только аудио в MP3 192 kbps, -16 LUFS нормализация, тёплый ламповый тембр.
- **Портативные архивы проектов (.whisp Project Bundles)**:
  - Экспорт всего состояния проекта (монтажный план, маркеры, субтитры, история, настройки, главы) в компактный файл `.whisp` (ZIP <200 КБ) в один клик.
  - Импорт архивов `.whisp` на любом компьютере без потери разметки и без пересчёта анализа.
  - Исключение тяжёлых медиафайлов для мгновенной пересылки проектов в команду монтажёров.
- **Оптимизация и расширение форматов**:
  - Поддержка скачивания аудиоформатов (`.mp3`, `.m4a`, `.wav`, `.whisp`) через API `/api/projects/{pid}/exports/{name}`.
  - Кнопка быстрого экспорта архива прямо в заголовке проекта и кнопка импорта на главном экране.

## 1.0.0 (Stable Release)

- **Мастер авто-монтажа по паттернам (Auto-Pattern Studio)**:
  - Готовые сценарии сборки в один клик: «Динамичный Shorts / Reels (Jump-Cut)», «Подкаст и диалог (Естественное дыхание)», «Лекция со слайдами (Синхронизация сцен)», «Удаление дублей и оговорок (Retakes)», «Сжатие пауз до ровной длины», «Тизер / Хайлайты».
- **Студийный таймлайн и аудио-скраббинг (Audio Scrubbing)**:
  - Прослушивание ультракороткого звукового среза при покадровом шаге стрелками (`←` / `→`) для точного поиска начала слов.
  - Полноэкранный просмотр Program Monitor (`~` / `F11`) в один клик.
  - Визуальная дорожка субтитров `T1` под аудиоволной с навигацией по клику.
  - Маркеры на таймлайне (`M`), редактирование заметок и экспорт в DaVinci Resolve Markers CSV.
  - Быстрый экспорт выделенного диапазона (`[In ... Out]`) в MP4.
- **Мастеринг звука и нормализация громкости (EBU R128)**:
  - Авто-нормализация звука под стандарты стримингов: -14 LUFS (YouTube, Shorts, TikTok, Reels), -16 LUFS (Подкасты, Spotify), -23 LUFS (ТВ / EBU R128).
  - Студийные пресеты эквализации голоса: «Подкаст», «Чёткость речи», «Теплота голоса», «Студийное радио».
  - Спектральное шумоподавление (`afftdn`) и автоматическое устранение щелчков на стыках склеек (declick 8 мс).
- **Стили вирусных субтитров для Shorts/Reels/TikTok (Hardsub)**:
  - «🔥 MrBeast Viral Shorts» (жирный жёлтый шрифт Impact, 5px обводка, 3D-тень).
  - «⚡ Cyber Neon» (бирюзовый текст с фиолетово-розовой обводкой).
  - «✨ Clean Minimal» (элегантный белый гротеск с мягкой подложкой).
  - Поддержка словаря терминов и имён (`initial_prompt`) для предотвращения галлюцинаций Whisper.
- **Текстовый монтаж видео (Text-Based Video Editing)**:
  - Монтаж видео прямо по тексту субтитров (как в Descript / Premiere Pro).
  - Вырезка и восстановление реплик в реальном времени.
  - Детектор запинок («эээ», «ммм») и слов-паразитов («ну», «короче», «типа», «как бы», «um», «uh», «like») с пакетным удалением.
- **Умные главы для YouTube (Smart Chapters Generator)**:
  - Интеллектуальная разбивка на смысловые разделы на основе реплик, смены сцен и пауз.
  - Форматирование таймкодов с учётом монтажных вырезок (`00:00 Введение`, `01:25 Тема`...).
  - Копирование готового таймлайн-описания для описания видео YouTube в буфер обмена.
- **Авто-кадрирование под Shorts / Reels / TikTok (9:16)**:
  - Рендер вертикальных клипов 9:16 с центрированием кадра или с размытыми полями.
- **Менеджмент проектов и файловая гигиена**:
  - Быстрый поиск по проектам и сортировка (по дате, названию, длительности).
  - Создание копии проекта (дублирование) в один клик.
  - Очистка кэша и временных файлов прокси/миниатюр с подсчётом освобождённого места.
- **Захват стоп-кадров (HD Thumbnail Grabber)**:
  - Сохранение любого кадра в оригинальном разрешении 1080p/4K прямо из таймлайна.
- **Проверка обновлений (Update Checker)**:
  - Проверка новых релизов на GitHub из раздела «Настройки» со 100% поддержкой оффлайн-режима.
- **Экспорт в профессиональные видеоредакторы**:
  - Adobe Premiere Pro (XML xmeml v5), DaVinci Resolve (FCPXML 1.9 + Markers CSV), Final Cut Pro, EDL CMX3600, OpenTimelineIO.
- **Интерфейс, локализация и безопасность**:
  - Полная поддержка Русского и Английского языков.
  - Горячие клавиши Premiere Pro, DaVinci Resolve и Whisp.
  - Интерактивный обучающий тур для быстрого старта.
  - Защита от закрытия окна при активном рендере (`beforeunload`).
  - Защита от Path Traversal, изоляция `127.0.0.1`, безопасная отдача MIME-типов Windows.

## 0.3.0

- **Единый exe**: FFmpeg, Auto-Editor и Whisp внутри одного `WHISP_MEDIA_DESK.exe`, без консоли, в своём окне (WebView2),
  с запасным открытием в браузере. Нативные диалоги выбора файла и папки. Установщик Inno Setup — по желанию.
- **Whisp встроен** (1.2.2, без изменений в `app/vendor/whisp`): модели, язык, устройство, длина строки, VAD, перевод на другой
  язык через NLLB-200. Загрузка моделей с прогрессом и отменой, папка моделей настраивается.
- **Новый интерфейс**: список проектов с превью и статусами, шаги «Видео и анализ — Монтаж — Субтитры — Экспорт» с подсказкой,
  что делать дальше, карточки профилей и моделей, панель задач, настройки, светлая и тёмная темы, понятные тексты.
- Сборка: onefile `whisp_desk.spec`, `tools/fetch_tools.ps1`, проверки exe в Actions (в том числе настоящее распознавание).
- Перевод субтитров попадает в экспорт с пересчётом времени под монтаж.
